\# Проект автоматизации тестирования Saucedemo.com



\## Описание проекта

Автоматизированные тесты для интернет-магазина \[SauceDemo](https://www.saucedemo.com/) с использованием Selenium WebDriver.



\## Технологии

\- Python 3.14

\- Selenium WebDriver

\- WebDriver Manager

\- Firefox (GeckoDriver)
